# Dependencies and third-party assets

## Runtime dependencies

**None.** The app is plain HTML5, CSS3 and JavaScript (ES5+ with standard browser APIs such as `fetch`). It loads no external scripts, stylesheets, fonts, analytics or CDNs.

| Item | Source | Licence |
| --- | --- | --- |
| Fonts | The visitor's system font (`system-ui` stack), so no font files are shipped | n/a |
| Icons | Simple inline SVG icons drawn for this project in `js/app.js` and `index.html` | © 2026 Saneed Ullah, see [LICENSE](LICENSE) |
| Images | None | n/a |

## Development tools (not shipped)

These are only needed to run the app locally. Use **one** of them:

| Tool | Purpose | Licence |

| [Python 3](https://www.python.org) `http.server` module | Local static web server | Python Software Foundation License |
| [`serve`](https://www.npmjs.com/package/serve) via `npx` (Node.js) | Local static web server | MIT |

## Content sources

The quiz explanations summarise, and link to, public guidance from Swiss federal offices. No text or images were copied from them.

- Natural Hazards Portal (Federal Office for the Environment and partners): https://www.natural-hazards.ch
- Federal Office of Public Health (FOPH): https://www.bag.admin.ch/en/heat
- MeteoSwiss: https://www.meteoswiss.admin.ch
